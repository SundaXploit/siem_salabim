aktif setelah redesain, lihat docs/DESIGN_TOKENS.md, docs/DESIGN_DIRECTION.md,
dan docs/REDESIGN_DELIVERY.md. Versi dependency tetap mengacu pada lockfile.

Tanggal analisis : 11 November 2026, Asia/Jakarta
Versi aplikasi  : 0.1.0, berdasarkan file VERSION
Cakupan         : kode proyek pada working tree saat analisis, terutama frontend
Metode          : inspeksi manifest, lockfile, CSS, JavaScript, Blade, route,
                  controller, service, model, migration, konfigurasi, dan CI.

Catatan pembacaan:
- Ini dokumentasi implementasi yang ditemukan, bukan rancangan teknologi baru.
- Versi terkunci berasal dari package-lock.json dan composer.lock. Constraint
  adalah rentang di package.json/composer.json, bukan versi runtime server.
- Konversi rem ke px di bawah mengasumsikan ukuran font root browser 16px.
  Body aplikasi 14px tidak mengubah arti 1rem menjadi 14px.
- Nilai CSS merupakan spesifikasi sumber, belum pengukuran computed style atau
  pemeriksaan visual di browser. Inline style dan specificity dapat mengubahnya.
- Default konfigurasi dijelaskan dari config/*.php dan .env.example; isi .env
  operasional tidak digunakan untuk menyimpulkan konfigurasi deployment aktif.


1. GAMBARAN APLIKASI DAN ARSITEKTUR
----------------------------------
SIEM Salabim adalah dashboard Security Operations Center untuk memantau alert
Wazuh, melakukan triage, mengirim notifikasi Telegram, melihat aktivitas analyst,
dan mendapatkan bantuan analisis AI.

Arsitektur utama:
  Browser
    -> Laravel web routes + session authentication
    -> Controller + service + Eloquent/query builder
    -> Database aplikasi
    -> Blade menghasilkan HTML
    -> Alpine.js + JavaScript memperbarui interaksi dan sebagian konten

Aliran data integrasi:
  Wazuh / Wazuh Indexer / OpenSearch
    -> job ingestion -> database lokal aplikasi
    -> dashboard, Live Alerts, detail, triage, riwayat, leaderboard
    -> layanan AI dan Telegram melalui backend

Kesimpulan: monolit Laravel dengan HTML dirender di server dan interaksi
JavaScript bertahap. Navigasi utama memakai URL/route Laravel. Tidak ditemukan
React, Vue, Next.js, Nuxt, Inertia, Livewire, atau router SPA pada implementasi
frontend yang diperiksa. Folder frontend menggunakan JavaScript, bukan TypeScript.

5. TIPOGRAFI DAN FONT FAMILY
----------------------------
Font utama UI: Inter.
  Stack token --font-sans:
  'Inter', ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
  'Segoe UI', sans-serif.

Font data teknis: IBM Plex Mono.
  Stack token --font-mono:
  'IBM Plex Mono', 'Fira Code', 'Cascadia Code', ui-monospace,
  SFMono-Regular, Menlo, Monaco, Consolas, monospace.

Pemuatan font di app.css:
- Inter: optical size 14..32, weight 400, 500, 550, 600, 650, 700.
- IBM Plex Mono: weight 400, 500, 600.
- Google Fonts memakai display=swap; fallback tampil selama font belum tersedia.
- Fira Code/Cascadia Code adalah fallback, tidak ikut diunduh dari import ini.
- Installer menyebut Inter dalam font-family tetapi tidak mengimpor Google Fonts
  maupun app.css sendiri; ketersediaan Inter tidak dijamin oleh halaman itu.

Penggunaan:
- Inter: navigasi, judul, label, tombol, isi teks, form, dan tabel umum.
- IBM Plex Mono: angka statistik, waktu, nilai teknis, JSON, beberapa rank dan
  nilai leaderboard, melalui --font-mono dan font-variant-numeric: tabular-nums.
- .font-technical, .technical-value, .data-table .technical, dan .time-display
  mempunyai aturan font teknis bersama.
- Sebagian IP/rule/chat ID dalam Blade memakai font-family:monospace inline.
  Bagian tersebut menggunakan monospace browser, tidak otomatis IBM Plex Mono.

Aturan body:
  font-size: var(--text-base) = 0.875rem = 14px
  line-height: 1.5, setara sekitar 21px pada body 14px
  text-rendering: optimizeLegibility
  -webkit-font-smoothing: antialiased

Weight umum:
  400 = teks biasa
  500 = item navigasi dan sebagian nilai pendukung
  600 = tombol, label, angka statistik, teks data utama
  650 = heading, section label, judul card, beberapa angka leaderboard
  700 = terdapat pada beberapa teks inline
Weight yang ditulis pada font fallback/monospace tetap bergantung pada face
font yang tersedia. Contohnya IBM Plex Mono hanya diminta sampai weight 600.

  melalui getComputedStyle(document.documentElement).

18. INTEGRASI, QUEUE, DAN SCHEDULER
-----------------------------------
OpenSearch / Wazuh:
- Integrasi HTTP melalui Guzzle ke indexer, default pola indeks wazuh-alerts-*.
- OpenSearch adalah sumber alert; database aplikasi menyimpan data operasional
  yang dipakai halaman, triage, notifikasi, dan riwayat.

- Provider AI dipanggil backend; frontend meminta hasil lewat route aplikasi.
- Konfigurasi model adalah pilihan provider, bukan paket runtime frontend.
- Timeout default config dashboard 90 detik; per alert 60 detik.

  Queue ai      : GenerateDashboardInsight
  Queue exports : GenerateDataExport dan pekerjaan purge terkait
  Queue updates : ApplyApplicationUpdate
